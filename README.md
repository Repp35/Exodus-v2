# Exodus Hub

Esta versão recupera os módulos e os caminhos de funcionamento do v2, com correções pontuais. A reescrita completa do hub ainda não está concluída.

Execute pelo loader:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Repp35/Exodus-v2/main/exodus%20hub/loader.luau"))()
```

Os módulos estão em `exodus hub/modules`. O loader utiliza uma revisão única do repositório para carregar os arquivos.
