# Exodus v2

Hub Roblox em Luau. O carregador está em `exodus hub/loader.luau`; os módulos ficam em `exodus hub/modules` e as ferramentas de formatação em `exodus hub/indeed`.

Os scripts de verificação simulada estão em `tests`. O comportamento em partida depende da versão atual do jogo e precisa ser verificado no Roblox.
