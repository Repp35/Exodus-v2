# Exodus v2

Hub Roblox/Luau com uma biblioteca de UI independente e reutilizável.

- [UI Library: instalação, catálogo e API](ui-library/README.md)
- [Análise da UI original, arquitetura e validação](docs/UI-REBUILD.md)
- [Showcase independente para Roblox Studio](ui-library/examples/showcase.client.luau)

As fontes da biblioteca estão em `ui-library/src`. O arquivo `exodus hub/modules/front/library.luau` é gerado com `python3 ui-library/scripts/build.py`. A integração específica do Exodus permanece em `exodus hub/modules/front/ui.luau`.
